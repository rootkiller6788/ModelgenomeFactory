# 核心链路零第三方依赖 —— 一个 pip 包都不需要。
#
# 这个项目**不训练、不下载权重**：它读的是 config.json 与参数清单（名字 + 形状），
# 全部计算都是字符串归一化、形状算术与 sha256。所以标准库足够，而且必须足够 ——
# 「结构证据」这种东西不应该依赖一个三年后可能装不上的包。
#
# 唯一的外部数据是 HF 的 safetensors.total（参数量真值），它**已经抄进 data/zoo/zoo.json**，
# 所以运行时不需要网络。要重新核对那些数字时才需要联网或安装 safetensors。
#
# 开发期需要 pytest（仅测试用，不进核心链路）：
#   python -m pip install pytest
